# Manna App V1.0 测试用例

依据：`Manna-V1.0 产品需求文档`（千寻，2026-08-22）及祷告 / 灵修 / 答题 / 读经 / 个人中心流程原型。  
对照实现：`前端/manna`。  
原则：**按需求逐条验收至全部通过**，不分期放行。未勾选视为未完成。

| 项 | 说明 |
|---|---|
| 被测包 | Manna（`APP_KEY=manna`）iOS / Android / H5 |
| 数据 | 后端已灌 `seed_manna.py`；Admin Scope=`manna` 可改文案 |
| 账号 | 设备登录即可；OAuth 用例单独标注 |
| 时段 | 早卡 **06:00–17:00**；晚卡 **17:01–05:59**（次日） |
| 记法 | `[ ]` 未测 · `[x]` 通过 · `[F]` 失败（备注缺陷号） |

---

## 0. 环境与冒烟

### TC-0001 冷启动进入首页
- **前置：** 已安装；网络正常；后端可用。
- **步骤：** 杀进程后打开 App。
- **期望：** 完成 Welcome / 登录（或静默设备登录）后进入 Home；底 Tab 为 Home / Quiz / Devotion / Bible / Me。不出现 Selah 品牌。

### TC-0002 断网空态与失败兜底
- **步骤：** 断网后分别打开 Home、灵修列表、答题首页、读经。
- **期望：** 成功但空列表显示空态文案；仅请求失败才允许 soft demo，不得把 demo 当主路径。

### TC-0003 Admin 改文案端上可见
- **步骤：** Admin（Scope=`manna`）改今日早经文一条 → 客户端下拉或重进 Home。
- **期望：** 首页经文与后台一致；停后端才可能本地 fallback。

## 1. 首页 · 每日经文 / VerseCard

### TC-1001 早卡时段
- **前置：** 系统时间调到 06:00–17:00。
- **期望：** 展示当日**早**经文：正文、出处、背景图；Amen 为当日早祷入口。

### TC-1002 晚卡时段
- **前置：** 系统时间调到 17:01–05:59。
- **期望：** 展示当日**晚**经文与晚祷入口；与早卡内容可不同（以后台配置为准）。

### TC-1003 跨 17:00 切换
- **步骤：** 16:59 停留 Home → 等到 17:01（或改系统时间后杀进程重进）。
- **期望：** 经文与背景切到晚卡；无需清缓存才能更新。

### TC-1004 早晚祷红点
- **前置：** 当日该时段尚未 Amen。
- **期望：** 首页 Amen 入口有红点；完成该时段首次祷告后红点消失。另一时段未做时，进入该时段仍有红点。

### TC-1005 收藏 VerseCard
- **步骤：** 首页收藏当日卡片。
- **期望：** Me → 收藏可见该卡（经文摘要、出处、日期、可取消收藏）。

### TC-1006 分享 / 下载 VerseCard
- **步骤：** 分享当日卡片。
- **期望：** 生成带品牌的图片（背景图 + 经文 + 出处）；拉起系统分享；支持保存到本地。不是纯文本分享。

### TC-1007 首页轻音乐跨页
- **步骤：** Home 播放轻音乐 → 点 Amen 进祷告页。
- **期望：** 祷告页延续同一首与播放/暂停状态（与听经播放器独立）。

### TC-1008 埋点 verse_view / verse_share
- **期望：** 查看当日经文上报 `verse_view`（`verse_id`, `verse_ref`）；分享上报 `verse_share`（`verse_id`, `share_platform`）。

## 2. 祷告

### TC-2001 经文页 Amen 进入祷告详情
- **步骤：** Home 点 Amen。
- **期望：** 进入祷告详情：经文、出处、祷告词；背景轻音乐状态同首页。上报 `prayer_start`（含 `prayer_period` 早/晚、`trigger_source`）。

### TC-2002 祷告词页曝光
- **期望：** 进入详情上报 `prayer_content_show`；离开时带 `duration_seconds`。

### TC-2003 完成早晚祷
- **步骤：** 详情页再点 Amen。
- **期望：** 进入祷告结果页；上报 `prayer_complete`。当日该时段红点清除。

### TC-2004 结果页积分与周历
- **期望：** 展示信仰值总分；本次 **+10 Manna**；一周打卡条：当日早或晚做过任意一次即点亮；未打卡日置灰。

### TC-2005 结果页四宫格跳转
- **期望：** 祷告时长 / 灵修时长 / 答题题数 / 读经时长（含听经）可点击进入对应模块。

### TC-2006 结果页返回首页
- **步骤：** 点返回。
- **期望：** 回到 Home，不丢登录态。

### TC-2007 收藏祷告全文
- **步骤：** 详情页收藏。
- **期望：** 收藏整篇（经文 + 出处 + 祷告词）。Me → 收藏与 VerseCard 同列表；点击进入祷告详情。

### TC-2008 分享祷告长图
- **步骤：** 详情页分享。
- **期望：** 品牌**长图**（经文 + 出处 + 祷告词）；系统分享 + 可存本地。

### TC-2009 早/晚详情可切换
- **步骤：** 在祷告页切换 morning / night（若入口存在）。
- **期望：** 文案、图标（日/月）、内容随 kind 变化，且符合当前或手动选择的时段。

## 3. 灵修

### TC-3001 列表标签
- **期望：** 横滑标签含 All、My Devotions、以及运营配置主题（如 Anxiety / Healing / Hope / Peace / Anger / Depression）。切换标签列表变化。

### TC-3002 All · 每日推荐包
- **期望：** 顶部为**用户未学过**的推荐课程包（后台可配）：名称、节数；其下展示该包第 1、2 节（课名 + 经文出处）。其余为其他课程包（封面、名称、节数）。

### TC-3003 主题下推荐
- **步骤：** 点某一主题标签。
- **期望：** 该主题有一条后台配置的推荐包；规则同 TC-3002。

### TC-3004 My Devotions
- **前置：** 至少有一个课程包已学 ≥1 节。
- **期望：** 只列出学过的包；最新学习的在最前；封面、名称、进度、总节数。**已学完全部课的包灰色显示**。

### TC-3005 未开课空态
- **前置：** 新账号，My Devotions 为空。
- **期望：** 展示未开启课程状态，不崩溃、不套用 demo 列表。

### TC-3006 进入课程包详情
- **步骤：** 点课程包卡片。
- **期望：** 封面、名称、总节数、牧师头像与姓名、概述；课节列表含课名 + 经文出处；**已学课灰色**。

### TC-3007 进入课节
- **步骤：** 点某一课。
- **期望：** 展示当前第几节、课名、经文与出处、正文；底部 Amen。

### TC-3008 Amen 完成课节
- **步骤：** 点 Amen。
- **期望：** 进入灵修结果页：+10 Manna、总分、周打卡（**当日学任意一节即点亮**）、四宫格可跳转；返回灵修列表。

### TC-3009 进度记忆
- **步骤：** 学完第 1 节 → 回详情。
- **期望：** 第 1 节灰显；进度更新；My Devotions 出现该包。

## 4. 答题

### TC-4001 答题首页
- **步骤：** 点 Tab Quiz。
- **期望：** 进入答题页（非其它 Tab）；展示当前等级与信仰分总值。

### TC-4002 L1 三道选择题
- **期望：** 一关 3 题，每题 3 选项；进度 1/3、2/3、3/3。第 1、2 题 Next 进下一题。

### TC-4003 L1 全对通关
- **步骤：** 三题全对。
- **期望：** 通关成功页；本关 +Manna（如 +30，以后台为准）；有下一关入口；结果区含四宫格（同祷告结果）。

### TC-4004 L1 任意一题错误即失败
- **步骤：** 三题中任意一题选错（含第 1 题或第 3 题）。
- **期望：** **立即或本关结束进入失败页**（不得在仍有错题时判通关）。失败页：错题展示用户选项 + 正确答案；对题只展示正确答案；扣除 Manna（如 −10，**以后台配置为准**）。

### TC-4005 失败页操作
- **期望：** Try Again 重打本关；Review 回顾本关三题；有下一关入口（规则与产品稿一致）。

### TC-4006 中途返回
- **步骤：** L1 做到第 2 题点返回。
- **期望：** 回到答题首页，并记住当前等级。**再次进入从本关第 1 题开始**，不从第 2 题续。

### TC-4007 In Bible
- **步骤：** 答题中点定位到圣经原文。
- **期望：** 打开对应经文位置；可返回继续答题。

### TC-4008 L2 快问快答
- **期望：** 60 秒计时、6 道判断题；全对成功；任意一题错失败。结算与积分规则同 L1。

### TC-4009 L3 解锁故事卡弹层
- **步骤：** 在成功或失败页点第 3 关（或达到解锁节点）。
- **期望：** 弹出故事解锁说明；Learn 进入知识点学习；Give Up 与点叉同效。

### TC-4010 Give Up 后再进
- **步骤：** Give Up / 叉 → 再打 L1、L2。
- **期望：** 仍在第 3 关节点解锁故事，不丢解锁资格。

### TC-4011 三个知识点学习
- **期望：** 故事图、名称、进度 1/3→3/3；GET 下一个知识点；全部掌握后出现完成页，Test Now 进入测试。

### TC-4012 学习中返回 / 杀进程
- **步骤：** 学到第 2 个知识点返回答题首页再进；或杀 App 再进。
- **期望：** **从知识点学习处续**（不是从 Quiz 首页把学习进度清零）。

### TC-4013 故事测试
- **期望：** 对三个知识点作判断测试；通过后解锁该故事卡，可在个人中心查看图文解说。

### TC-4014 未解锁故事卡
- **步骤：** Me 或故事列表点未解锁卡。
- **期望：** 弹窗引导去答题解锁；Take Quiz 进入答题。已解锁卡进入故事详情。一期可不展示「Lv.x 即可解锁」文案（原型标注）。

## 5. 读经 / 听经

### TC-5001 打开读经
- **期望：** 按书卷、章节浏览完整经文；当前译本（如 WEB / KJV）与书名、章号展示正确。

### TC-5002 目录与译本
- **步骤：** 点译本 / 书名章号。
- **期望：** 可切换译本、书卷、章节。

### TC-5003 阅读设置 Aa
- **步骤：** 点 Aa。
- **期望：** 可选字体；可选字号（**默认 16**）；**三种阅读模式**；关闭弹层后设置保留。

### TC-5004 长按经文
- **步骤：** 长按某节。
- **期望：** 文字波浪线选中；弹出 Amen / Note / VerseCard / Copy。

### TC-5005 Amen
- **步骤：** 对一节 Amen。
- **期望：** 原文标记 Amen 并计数（全平台聚合数据，允许略有延迟）；可再次操作符合产品规则。

### TC-5006 笔记
- **步骤：** Note → 输入 → SAVE。
- **期望：** 保存成功；Me → 学习记录 / Notes 可见；可再编辑。

### TC-5007 高亮
- **步骤：** 点某一颜色圆圈；再点**同一颜色**。
- **期望：** 经文被该色标注；再点同色**取消**高亮。Me → Highlight 同步。

### TC-5008 制作 VerseCard
- **步骤：** VerseCard → 切换背景 → 保存。
- **期望：** 按所选经文出卡；保存到个人中心；可分享/下载规则同首页卡。

### TC-5009 复制
- **步骤：** Copy。
- **期望：** 所选经文进入剪贴板。

### TC-5010 书签
- **步骤：** 加入书签。
- **期望：** Me 可查看该书签；可取消。

### TC-5011 搜索
- **步骤：** 打开搜索 → 输入关键字（≥2 字符）。
- **期望：** 展示结果条数；每条含书、章、经文；**关键字加粗**；点结果跳到对应章。空结果有空态。

### TC-5012 搜索历史
- **期望：** 有最近搜索；可删除单条或清空；点历史可再次搜索。

### TC-5013 进入听经
- **步骤：** 读经页点播放。
- **期望：** 进入听经页：书名+章、当前节高亮、进度可拖、播放/暂停。

### TC-5014 倍速
- **期望：** 可选 0.5x / 1x / 1.5x / 2x（以产品实际档位为准，档位展示正确且生效）。

### TC-5015 定时关闭
- **期望：** 15 / 30 / 60 / 90 min（或稿面档位）到期停止播放。

### TC-5016 音色
- **期望：** Male / Female（及稿面选项）切换后播放对应音轨；缺资源有明确提示。

### TC-5017 背景音乐
- **期望：** 听经 BGM 可开可关，不覆盖经文朗读。

### TC-5018 整书下载
- **步骤：** 下载当前书（如 Genesis 全书）。
- **期望：** 按章下载完整书；进度可见。

### TC-5019 非 Wi-Fi 下载确认
- **前置：** 仅蜂窝网络。
- **期望：** 弹窗 “whether to continue downloading?”；Cancel 不下载；Continue 继续。

### TC-5020 迷你播放条
- **步骤：** 听经中返回读经或其它 Tab。
- **期望：** 底部悬浮小卡：章节、进度、暂停、关闭。关闭后停止播放。读经页当前播放节保持高亮（若仍在该章）。

## 6. 个人中心

### TC-6001 总览
- **期望：** 总 Manna 可点进账本；四宫格：Pray 分钟、Devotion 分钟、Read 分钟（**含听经**）、Quiz 题数；点击进入对应功能。

### TC-6002 账本
- **步骤：** 完成一次祷告或灵修 +10 后打开账本。
- **期望：** 余额与入账记录一致。

### TC-6003 日历样式
- **期望：** 当天高亮；**使用过任一项功能的日期**为「有记录」样式；未使用为另一样式。点日期看当日任务。

### TC-6004 当日任务列表
- **期望：** Morning Prayer / Night Prayer / Devotion / Bible / Quiz。  
  - 已完成：完成样式，**不可再点去完成**。  
  - 未完成：可点击跳到对应功能。  
  - 灵修：当日学**任意一节**即完成。

### TC-6005 收藏列表
- **期望：** VerseCard（文字摘要、出处、日期、取消收藏）与**收藏的祷告词**混排；点祷告项进祷告详情。

### TC-6006 故事卡列表
- **期望：** 已解锁可进图文详情；未解锁点出解锁弹窗（同 TC-4014）。

### TC-6007 Bible Hub
- **步骤：** Me → Bible。
- **期望：** 分栏 Progress / Note / Highlight / Bookmark / VerseCard 均有内容或空态；Progress 展示书卷进度（如 25%）。

### TC-6008 设置
- **期望：** 隐私协议、关于我们、用户权益等可打开，无白屏。

### TC-6009 统计跳转
- **步骤：** 点四宫格各项。
- **期望：** 分别进入祷告、灵修、读经（或听经）、答题，不进错模块。

- **期望：** 学完一节 Amen 后 +10。

- **期望：** 成功加分、失败扣分与 Admin 配置一致；余额不为负时的表现符合产品规则（若允许为 0 则停在 0）。

## 8. 运营 / 后台 / 埋点

### TC-8001 后台发布早晚经文与祷告词

- **期望：** 客户端在对应时段展示新内容。

### TC-8002 后台灵修与题库
- **期望：** 改课程包/课节/题目后客户端刷新可见；答题失败扣分配置生效（TC-4004）。

### TC-8003 推送 · 灵修提醒
- **期望：** 每日定时收到灵修提醒（权限已开）；点击进入灵修。无权限时不反复崩溃。

### TC-8004 推送 · 祷告打卡提醒
- **期望：** 未完成该时段祷告时能收到提醒；已完成后不再误推或文案区分已完成。

### TC-8005 推送 · 每日答题提醒
- **期望：** 定时收到答题提醒，点击进入 Quiz。

- **步骤：** 进入 Home、祷告、灵修、答题、读经、Me。
- **期望：** 各页上报 `page_view`，`page_name` 可区分页面；登录后带 `user_id`。

### TC-8007 数据看板（运营）
- **期望：** 后台可看用户活跃、功能使用率、打卡率；数字与抽检账号行为方向一致。

### TC-8008 圣经全文与音频内容
- **期望：** 核心章可读可听；全量书卷/音频按运营是否已灌库验收（未灌库则缺章有明确提示，不白屏）。
